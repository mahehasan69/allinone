# The Digital Library

A realistic, browser-based PDF flipbook reader.

## Features
- 3D page-turning reader powered by StPageFlip
- PDF rendering powered by PDF.js
- Mobile-friendly layout, swipe/drag, keyboard navigation, fullscreen and zoom
- PDFs are selected and processed locally in the visitor's browser; files are not uploaded

## Deploy with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment → Source**, select **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. Wait for the Pages deployment. The site URL will be shown in Settings → Pages.
